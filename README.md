# Rezolvări Gazeta Matematică 2025-2026

[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/andr3eee1/GM2025-2026)

This repository contains personal solutions to selected problems from the Romanian mathematics journal *Gazeta Matematică* (GM). All solutions are written using the [Typst](https://typst.app/) typesetting system.

The primary goal is to provide clear, step-by-step solutions for challenging high-school and competition-level math problems.

## Repository Structure

The solutions are organized into `.typ` files based on the magazine's issue number.

-   `X.typ`: Contains problems from issue number `X`.
-   `sX.typ`: Contains problems from the supplement of issue number `X`.
-   `/pdf/`: Contains pre-compiled PDF versions of the solutions for easy viewing and printing.
-   `/img/`: Contains images and diagrams used in the Typst documents.

## Usage

You can browse the source code directly in the `.typ` files. For a properly formatted view, it is recommended to check the pre-compiled files in the `/pdf/` directory.

To compile the source files yourself, you need to have Typst installed. You can then run the following command in your terminal:
```bash
typst compile <filename>.typ
```
